# Assignment 5

This folder contains two Python tasks about dictionaries and list operations.

## Task 1 - Student Marks Lookup

This program uses a dictionary to store student names and their marks.

It has a dictionary called student_details with four students (raman, reena, runnu, brandon) and their marks. It asks you to enter a student's name, then strips any extra spaces and converts it to lowercase so the search is case-insensitive.

If the name exists in the dictionary, it prints that student's marks with the name in title case. If the name isn't found, it prints "Student not found."

## Task 2 - List Slicing and Reversing

This program creates a list, extracts part of it, and reverses the extracted part.

First it creates a list of numbers from 1 to 10 using a list comprehension. Then it extracts the first five elements using slicing (index 0 to 5). After that it reverses the extracted list using slice notation with a step of -1.

Finally it prints all three lists - the original list, the extracted first five elements, and the reversed version of the extracted elements.
